# LIGAT CMS — Deploy Guide

**Tanggal:** 22 Mei 2026
**File:** `ligat-cms-deploy.tar` (1.2 MB)

---

## 1. Upload ke Server

```bash
scp ligat-cms-deploy.tar user@157.15.40.90:/var/www/ligat-cms/
```

Atau upload via panel hosting (cPanel → File Manager).

---

## 2. Ekstrak di Server

```bash
cd /var/www/ligat-cms
tar -xf ligat-cms-deploy.tar
mv ligat-cms/* .
rmdir ligat-cms
rm ligat-cms-deploy.tar
```

---

## 3. Install Dependencies

```bash
composer install --no-dev --optimize-autoloader
```

---

## 4. Konfigurasi .env

```bash
cp .env.example .env
php artisan key:generate
```

Variable yang **wajib diisi**:

| Variable | Contoh Value | Keterangan |
|----------|-------------|-----------|
| `APP_ENV` | `production` | |
| `APP_DEBUG` | `false` | |
| `APP_URL` | `http://157.15.40.90:8080` | URL server |
| `DB_DATABASE` | `mentari` | |
| `DB_USERNAME` | `root` | |
| `DB_PASSWORD` | `isi_password` | |
| `FIREBASE_PROJECT_ID` | `app-ligat` | Firebase project |
| `FIREBASE_CREDENTIALS` | `firebase-credentials.json` | Simpan di `storage/app/` |

---

## 5. Storage & Cache

```bash
# Storage link
php artisan storage:link

# Cache
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Permission
chmod -R 775 storage bootstrap/cache
chmod -R 775 public/storage
```

---

## 6. Firebase Credentials

Upload `firebase-credentials.json` (service account key dari Firebase Console):

```bash
nano storage/app/firebase-credentials.json
# Paste isi JSON, Ctrl+X, Y, Enter
```

---

## 7. Migrate & Seed (Jika DB Baru)

```bash
php artisan migrate
php artisan db:seed --class=DatabaseSeeder
```

---

## 8. Web Server (Apache)

```apache
<VirtualHost *:8080>
    DocumentRoot "/var/www/ligat-cms/public"
    ServerName 157.15.40.90
    <Directory "/var/www/ligat-cms/public">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```

**Symlink** (alternatif):
```bash
ln -s /var/www/ligat-cms/public /var/www/html/ligat-api
```

---

## 9. Verify

| URL | Keterangan |
|-----|-----------|
| `http://157.15.40.90:8080/` | CMS Login |
| `http://157.15.40.90/ligat-api/` | Via symlink |
| `http://157.15.40.90/ligat-api/api/` | API Endpoints |

---

## 10. Catatan

- Token **Fonnte** dan **FCM** sudah tersimpan di DB, tidak perlu di-set ulang
- Pastikan folder `storage/` dan `bootstrap/cache/` writable
- Jika ada error 500, cek `storage/logs/laravel.log`
